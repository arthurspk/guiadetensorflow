## :dart: O guia para alavancar a sua carreira

> TensorFlow é a plataforma de machine learning open source criada pelo Google em 2015: você define, treina e coloca em produção modelos de deep learning, do protótipo em um notebook até o app rodando no navegador ou no celular. Com o Keras como API oficial de alto nível, o TensorFlow cobre o ciclo inteiro — dados, treino, avaliação e deploy (TensorFlow Lite/LiteRT no mobile, TensorFlow.js no navegador, TFX em produção). Hoje o PyTorch é a alternativa dominante em pesquisa e em boa parte das vagas de machine learning, então este guia também te ajuda a entender quando cada um faz mais sentido. Reunimos aqui roadmap, trilha de entrada, cursos gratuitos e pagos, documentação, livros, canais, ferramentas, projetos práticos e um capítulo dedicado a usar IA no dia a dia de quem trabalha com machine learning — tudo verificado e organizado para quem está começando ou quer se aprofundar.

## 🚀 Por onde começar

1. **Aprenda o básico de Python.** Se você ainda não programa em Python, comece por [Getting Started with Python](https://www.python.org/about/gettingstarted/) — TensorFlow é, na prática, uma biblioteca Python.
2. **Entenda os fundamentos de machine learning** com o [Curso intensivo de machine learning do Google (em português)](https://developers.google.com/machine-learning/crash-course?hl=pt-br) — gratuito, com exercícios interativos.
3. **Teste sem instalar nada** no [Google Colab](https://colab.research.google.com/) — um notebook Jupyter na nuvem com TensorFlow já pré-instalado e GPU gratuita.
4. **Siga o tutorial oficial "Quickstart for beginners"** em [tensorflow.org](https://www.tensorflow.org/tutorials/quickstart/beginner) — seu primeiro modelo, em poucas linhas, usando Keras.
5. **Faça um curso introdutório gratuito em português:** [Curso de TensorFlow para Iniciantes (Didática Tech)](https://didatica.tech/curso-de-tensorflow-para-iniciantes/).
6. **Construa seu primeiro projeto de verdade:** o tutorial oficial [Classificação básica de imagens](https://www.tensorflow.org/tutorials/keras/classification), treinando uma rede para reconhecer roupas no dataset Fashion MNIST.
7. **Aprofunde com uma formação completa:** [Formação Deep Learning com TensorFlow e Keras (Alura)](https://www.alura.com.br/formacao-deep-learning-tensorflow-keras) — curso pago, mas leva do zero a redes convolucionais e geração de imagens.
8. **Construa e publique um projeto próprio no GitHub** — por exemplo, adaptando o tutorial de [classificação de imagens com redes convolucionais (Alura)](https://www.alura.com.br/curso-online-tensorflow-keras-classificando-imagens-redes-convolucionais) para um dataset diferente. Documentar isso no portfólio pesa mais que qualquer certificado.

## 📖 Documentação oficial

- [TensorFlow — Guide](https://www.tensorflow.org/guide) — Guia central de conceitos: instalação, migração para TF2, Keras, tf.data, práticas recomendadas, aceleração com GPU/TPU.
- [TensorFlow basics](https://www.tensorflow.org/guide/basics) — Fundamentos oficiais: tensores, variáveis, `tf.GradientTape`, `tf.function`, módulos e loops de treino.
- [Effective TensorFlow 2](https://www.tensorflow.org/guide/effective_tf2) — Boas práticas idiomáticas para código TF2 e guia de migração para quem vem do TF1.
- [TensorFlow API Reference (Python)](https://www.tensorflow.org/api_docs/python/tf) — Referência completa de todas as classes e funções do módulo `tf`.
- [TensorFlow — Versions](https://www.tensorflow.org/versions) — Lista de todas as versões com documentação, com o changelog de cada release estável.
- [Keras — documentação oficial](https://keras.io/) — Documentação da API de alto nível padrão do TensorFlow, hoje também multi-backend (TensorFlow, JAX, PyTorch).
- [LiteRT (antigo TensorFlow Lite)](https://developers.google.com/edge/litert) — O TensorFlow Lite foi renomeado para LiteRT: runtime oficial do Google para rodar modelos em dispositivos móveis e edge.
- [TensorFlow.js](https://www.tensorflow.org/js) — Biblioteca oficial para treinar e rodar modelos de machine learning diretamente no navegador ou em Node.js.
- [TFX — ML Production Pipelines](https://www.tensorflow.org/tfx) — Plataforma oficial ponta a ponta para pipelines de machine learning em produção.
- [TensorBoard](https://www.tensorflow.org/tensorboard) — Suíte oficial de visualização para acompanhar métricas, grafos e embeddings do treinamento.
- [TensorFlow Hub](https://www.tensorflow.org/hub) — Repositório oficial de modelos pré-treinados, prontos para reuso e transfer learning.
- [TensorFlow Datasets (TFDS)](https://www.tensorflow.org/datasets) — Catálogo oficial de datasets prontos para `tf.data`, de visão computacional a linguagem natural.
- [tensorflow/tensorflow (GitHub)](https://github.com/tensorflow/tensorflow) — Repositório oficial com o código-fonte, issues e discussões da comunidade.
- [Notas de release do TensorFlow](https://github.com/tensorflow/tensorflow/releases) — Changelog detalhado de cada versão lançada.
- [Blog oficial do TensorFlow](https://blog.tensorflow.org/) — Anúncios de versões, estudos de caso e novidades direto do time do Google.
- [Google Colab](https://colab.research.google.com/) — Ambiente oficial gratuito (com GPU/TPU) para rodar notebooks TensorFlow sem instalar nada.

## 🤖 IA na prática

TensorFlow é uma das áreas onde assistentes de IA erram mais silenciosamente: existem anos de tutoriais de TensorFlow 1.x, Keras standalone e APIs descontinuadas na internet, e o modelo de linguagem não sabe qual versão você está usando a menos que você diga. Use isso como ponto de partida, não como verdade absoluta.

**Para aprender**
- Peça para **explicar um erro de shape** (ex.: `ValueError: Input 0 of layer "dense" is incompatible with the layer`) junto com o resumo do modelo (`model.summary()`) — é um dos erros mais comuns em quem está começando com Keras.
- Peça para **comentar linha a linha** um trecho de código com `tf.GradientTape`, explicando o que cada chamada faz no cálculo do gradiente.
- Peça **exercícios com gabarito** sobre o tópico que está estudando (camadas convolucionais, regularização, `tf.data`) usando um dataset pequeno do TensorFlow Datasets.
- Cole a arquitetura de um modelo e peça para a IA sugerir **por que ele pode estar com overfitting** e quais técnicas testar (dropout, data augmentation, regularização).

**Para trabalhar**
- Use [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Claude Code](https://code.claude.com/docs/en/overview) para escrever camadas Keras repetitivas, gerar código de pré-processamento com `tf.data`, escrever testes para pipelines de treino e converter notebooks de exploração em scripts de produção.
- O [Gemini Code Assist](https://codeassist.google/) tem integração direta com o Google Colab, útil para quem já treina modelos TensorFlow por lá.
- Para partir de um modelo pronto em vez de treinar do zero, combine IA com um catálogo real: [KerasHub](https://keras.io/keras_hub/) (antigo KerasNLP) traz modelos pré-treinados prontos para usar com a API Keras 3/TensorFlow, e o [Vertex AI Model Garden](https://cloud.google.com/model-garden) reúne modelos do Google Cloud para implantar ou ajustar com poucos cliques.
- Depois de **qualquer** sugestão aceita, rode o treino em um subconjunto pequeno do dataset para conferir se o shape, o `loss` e a acurácia fazem sentido antes de rodar o treino completo (que pode levar horas).

**Limites e boas práticas**
- IA erra com frequência em **APIs antigas do TensorFlow 1.x** (`tf.Session`, `placeholder`, `tf.contrib`) misturadas com código TF2/Keras moderno — se aparecer algo assim, é sinal de que o modelo puxou um tutorial desatualizado.
- Ela também confunde a API standalone antiga do Keras (`import keras`) com a API atual embutida no TensorFlow (`from tensorflow import keras` ou `import keras` na versão multi-backend do Keras 3) — confirme sempre na [documentação oficial do Keras](https://keras.io/).
- Não cole dados sensíveis, datasets proprietários ou credenciais de nuvem (chaves de GCP/AWS) em ferramentas de IA sem a política da sua empresa.
- Entenda a arquitetura que você aceita: em entrevista técnica e em produção, o modelo — e os bugs dele — são seus.
